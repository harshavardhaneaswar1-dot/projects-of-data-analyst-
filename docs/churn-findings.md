# Project 2 — Telco Churn Findings

Dataset: `data/WA_Fn-UseC_-Telco-Customer-Churn.csv` — 7,043 customers (Telco demo). Report: `reports/project2.pbix`.

## Headlines

- Overall churn **≈ 26.5%** (1,869 / 7,043).
- **Month-to-month ≈ 42.7%** churn vs **two-year ≈ 2.8%** — contract term dominates.
- **Fiber optic ≈ 41.9%** churn, well above DSL.
- Highest risk: tenure 0–12 months + electronic check + paperless billing + no TechSupport.

## Takeaways

1. Migrate month-to-month users to 1–2 year contracts with incentives.
2. Fix Fiber optic value/quality perception (top complaint cluster).
3. Onboard the first year hard: TechSupport bundles, autopay discounts.
